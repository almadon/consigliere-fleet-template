# Credits

This repo is configuration and helper scripts. The software it drives is listed, with links, uses and licences, in the framework's [credits](https://github.com/almadon/Consigliere/blob/main/docs/credits.md).

The scripts here use [sops](https://github.com/getsops/sops), [age](https://github.com/FiloSottile/age), [PyYAML](https://github.com/yaml/pyyaml), the Python that ships with [Ansible](https://github.com/ansible/ansible), and bash. Their licences are recorded in the framework's table, where unchecked ones are marked VERIFY.
